# Зал — Telegram Mini App

Один файл `index.html`. Работает на GitHub Pages, сервер не нужен.
Данные хранятся в облаке Telegram (CloudStorage): они привязаны к твоему аккаунту и синхронизируются между телефоном и компьютером.

## 1. Выложить на GitHub Pages
1. Создай публичный репозиторий, например `gym`.
2. Положи в корень `index.html` и сделай push.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)` → Save.
4. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/gym/`. Можно проверить в браузере: вне Telegram данные сохраняются только в этом браузере.

## 2. Подключить к Telegram
1. В **@BotFather** выполни `/newbot` и создай бота (если его ещё нет).
2. Кнопка меню: `/mybots` → твой бот → **Bot Settings → Menu Button** → вставь URL из п. 1 и задай название кнопки, например «Зал».
3. Открой бота. Слева от поля ввода появится кнопка «Зал», она открывает приложение на весь экран.

Дополнительно можно создать прямую ссылку на приложение: `/newapp` в @BotFather. Получится ссылка вида `t.me/<бот>/<app>`, её удобно закрепить в чате с самим собой.

## 3. Обновления
Меняешь `index.html` → `git push`. Через 1–2 минуты Telegram откроет новую версию. Данные при этом не теряются: они хранятся в Telegram, а не в файле.

Если Telegram показывает старую версию, закрой приложение и открой снова.

## Иконка и обложка

- `cover-640x360.png` — обложка Mini App: @BotFather → `/newapp` (или `/editapp`), на шаге фото.

## Настройки программы
Всё в начале блока `<script>` в `index.html`:
- Упражнения, подходы и порядок теперь меняются прямо в приложении: «Ещё → Программа».
- `START` — понедельник первой недели (от него считаются A/B и разгрузка каждую 7-ю неделю);
- `CHECKPOINT` — дата контрольного замера;
- `EX` — упражнения: подходы, диапазон повторов (`lo`–`hi`), шаг прибавки (`step`), стартовый вес (`def`), техника;
- `WORKOUTS` — состав тренировок A и B.

## Ограничения
- Напоминаний нет, потому что нет сервера. Поставь повторяющееся напоминание в телефоне на Пн/Ср/Пт 06:15.
- Лимит CloudStorage — 1024 ячейки. Тренировки хранятся по месяцам, еда — по неделям, замеры — по месяцам: ~130 ячеек в год, хватит на 7+ лет. Сколько занято, видно в «Ещё → Настройки».
